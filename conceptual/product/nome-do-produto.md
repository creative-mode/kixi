# Nome do produto: registo e pergunta para a próxima demo

> Issue: [#613](https://github.com/creative-mode/kixi/issues/613) · Plano da próxima demo:
> [#615](https://github.com/creative-mode/kixi/issues/615)
> Origem: live demo de 13/11/2026 (4 alunos, formulário de feedback).
> Estado: observação registada; decisão adiada para a próxima amostra.

## O que se ouviu

- **R2** mudaria o nome para algo ligado a estudo e fácil de fixar.
- **R3** pediu que o nome não mudasse.

É um contra um. Com quatro participantes, isto não é uma tendência: é um sinal para voltar a medir.
Nesta ronda **não se muda o nome**. Regista-se a observação e volta-se a perguntar na próxima demo
([#615](https://github.com/creative-mode/kixi/issues/615)), com uma amostra maior.

## Pergunta para o formulário da próxima demo

Acrescentar ao formulário da #615, **depois do número da sessão**, para que cada resposta se possa
cruzar com as grelhas e as gravações. Manter a ordem das opções igual em todas as sessões.

### 1. Associação a estudo

**«Numa escala de 1 a 5, quanto é que o nome “Kixi” te faz lembrar estudo?»**

| 1 | 2 | 3 | 4 | 5 |
| --- | --- | --- | --- | --- |
| Nada |  |  |  | Muito |

### 2. Facilidade de memorização

**«Numa escala de 1 a 5, quão fácil é lembrares-te do nome “Kixi”?»**

| 1 | 2 | 3 | 4 | 5 |
| --- | --- | --- | --- | --- |
| Muito difícil |  |  |  | Muito fácil |

### 3. Intenção

**«Se pudesses decidir, o que farias ao nome?»**

- [ ] Manter «Kixi»
- [ ] Mudar
- [ ] Não sei / indiferente

### 4. Sugestão (só para quem respondeu «Mudar»)

**«Que nome sugerias?»** — resposta curta, opcional.

### 5. Porquê (opcional)

**«Porquê?»** — resposta curta, opcional.

> Não sugerir nomes nem dar exemplos no enunciado: uma sugestão dada pelo formulário contamina a
> resposta e deixa de se distinguir do que o aluno trouxe.

## Como ler o resultado

Registar na #615, por sessão:

| Sessão | n | Associação (média 1–5) | Memorização (média 1–5) | Manter | Mudar | Não sei | Sugestões |
| --- | --- | --- | --- | --- | --- | --- | --- |
|  |  |  |  |  |  |  |  |

- Considerar só respostas com número de sessão e sem campos obrigatórios em falta.
- Reportar o **n** em cada linha: uma média de duas respostas não vale o mesmo que uma de doze.
- Só levar uma mudança de nome a decisão se a intenção de mudar for maioritária numa amostra de
  pelo menos oito respostas **e** a associação a estudo continuar baixa (média inferior a 3) nessa
  mesma amostra. Caso contrário, manter o nome e voltar a observar.
- Guardar as sugestões textuais como os alunos as escreveram, sem corrigir a grafia, e agrupar só na
  análise, para não se perder o que quiseram dizer.
- Cruzar cada resposta com a sessão e com o horário de submissão, como pede a #615.
